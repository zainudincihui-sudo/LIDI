# LIDI

**See who moves first.**

LIDI is a social intelligence platform for on-chain traders on **Robinhood Chain**. It surfaces trending tokens, high-performing wallets, and live on-chain activity — so you can spot momentum before it shows up everywhere else.

🔗 **Live site:** https://zainudincihui-sudo.github.io/LIDI/

No wallet connection required — LIDI is a pure analytics platform.

---

## Features

- 🔥 **Trending Tokens** — discover memecoins gaining volume and holders
- 👀 **Smart Wallets** — find wallets with consistently strong performance
- ⚡ **Live Activity** — see on-chain transactions as they happen
- 🏆 **Leaderboard** — ranking of the best-performing traders
- 🔔 **Follow & Alerts** — track wallets and get notified when they act
- 🌙 **Light/dark mode**

## Status

This is an early-stage build. The interface is live, but data shown across the site is currently **sample/demo data** — it is not yet connected to real Robinhood Chain activity.

## Roadmap

- **V1 — Discovery**: tokens, wallets, and live activity
- **V2 — Social**: follow, profiles, and leaderboards
- **V3 — Intelligence**: the LIDI Score and smart alerts
- **V4 — AI**: automated analysis that surfaces opportunities

## Tech

Currently a static frontend (`index.html`) — no backend yet. Planned architecture (indexer, database, API) is documented in [`LIDI-Database-API-Spec.md`](./LIDI-Database-API-Spec.md).

## Built on Robinhood Chain

LIDI reads on-chain activity from [Robinhood Chain](https://robinhood.com/us/en/chain/), Robinhood's Ethereum Layer 2 network.
